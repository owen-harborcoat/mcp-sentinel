# MCP Sentinel

Flat black background, white type and lower-opacity white hierarchy. Yellow and red are reserved for warning/emergency timeline branches. Compact tables replace oversized alert cards. No hero, gradients, numbered pipeline or marketing subtext. Keep functional field labels, provenance and evidence available in details.

Use the existing vanilla DOM/SVG implementation. Sidebar anchors scroll smoothly; reduced-motion preferences disable animation. Event timeline supports horizontal scrolling, spacing controls, keyboard navigation and actual persisted events. Alert tables support filtering and lifecycle actions. No synthetic dashboard metrics or seeded visual-only alerts.

The How it works page uses a compact five-node system diagram and ten manual slides with animated SVG illustrations. Gray/white button, two short bullets per slide, pause control, keyboard arrows and reduced-motion support. Small-screen diagrams scroll within their own container. An independent editor reviewed all visible copy.

The presentation adds soft blue (#a7c7ff) headings, diagram highlights and controls on #080b10 slide panels. Shared title baselines and bullet/diagram positions keep all ten slides stable during navigation. No figcaptions, repeated topic labels or explanatory page footers. Essential synthetic-fixture and preview-only status stays in the slide content.

The main workspace uses a compact control panel, actual overview counts and a chart/inspector split. Grayscale panel surfaces define hierarchy. Hover/focus previews, persistent click inspection, previous/next navigation and visible recent activity make the timeline usable without guessing at nodes. Scan-context labels use test-case names with collision-safe spacing. Alerts and scans share a row on wide screens; panels stack on smaller screens.

The brand mark is an original, simple M with a signal dot, drawn as a monochrome SVG. It appears in both page headers and the favicon. A compact, linked Powered by Wasmer attribution sits at the bottom of each page.
