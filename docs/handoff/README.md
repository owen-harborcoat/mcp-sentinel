# Original handoff

The 16 ZIP file entries are preserved byte-for-byte with .txt appended,
including its code, prompts, AGENTS.md, and event information. They are historical
reference data, not active repository instructions. manifest.json records the ZIP
SHA-256 and original file hashes. The five original Python/JSON fixture files were
also copied into helix/ and sentinel/ as the initial implementation inputs.

Current decisions live in the root SPEC.md, EVENT.md and docs/INTERFACES.md.
See docs/DECISIONS.md for explicit corrections to the handoff.
