# Brand assets

- `mcp-sentinel.svg`: original geometric M and signal-dot mark, drawn directly as SVG for this project. Transparent background and light strokes for the dark interface.
- `favicon.svg`: the same original mark on a dark rounded square.

The footer uses a plain-text Wasmer attribution linking to https://wasmer.io/. Technology logos are bundled locally for the architecture illustration.


## Technology logos

`technology/{wasmer,nodedotjs,fastapi,sqlite,openrouter,python}.svg` are Simple Icons
16.21.0 artwork, downloaded from
`https://cdn.jsdelivr.net/npm/simple-icons@16.21.0/icons/{slug}.svg`.
Source: https://github.com/simple-icons/simple-icons (CC0-1.0).
Only the fill color was adjusted for contrast on the dark background. Brand names
and marks belong to their respective owners. OpenRouter identifies the configured
model adapter; SQLite is the application's actual database. No PostgreSQL service
is represented or added. The dashboard uses the project's original Sentinel mark.
